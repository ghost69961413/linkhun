# LinkHub Backend

LinkHub is a full-stack developer networking platform inspired by LinkedIn and GitHub.

This repository contains the backend built with Spring Boot, providing secure authentication, user management, developer profiles, project showcases, social networking features, and job management APIs.

## 🛠 Tech Stack

- Java 21
- Spring Boot 3.5
- Spring Security
- JWT Authentication
- Spring Data JPA
- MySQL
- Hibernate
- Lombok
- MapStruct
- Swagger/OpenAPI
- WebSocket
- Maven

- ## ✨ Features

- User Authentication (JWT)
- Developer Profiles
- Project Showcase
- Repository Showcase
- Posts & Feed
- Like & Comment System
- Follow Developers
- Job Portal
- Real-time Chat
- Notifications
- Admin Dashboard
