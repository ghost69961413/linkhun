# LinkHub frontend

React 19 + TypeScript + Vite app. For full local setup, Vercel deployment, backend configuration, and environment variables, see the repository [README](../README.md).

For local development, copy `.env.example` to `.env.local`, install with `pnpm install`, and run `pnpm dev`. Set `VITE_API_URL` to the Spring API root including `/api`.
